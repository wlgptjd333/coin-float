CoinFloat 개인정보 처리방침

시행일: 2026-10-30

1. 수집하는 정보
Google 계정 동기화를 쓰지 않으면 CoinFloat은 개인정보를 수집하지 않습니다. 로그인은 선택 사항이며, 로그인하지 않아도 모든 기능을 쓸 수 있습니다. 결제, 광고, 분석(애널리틱스) 도구는 없습니다.

2. Google 계정 동기화 (선택)
Google로 로그인하면 아래 정보가 Google의 Firebase 서비스(Authentication, Cloud Firestore)에 저장됩니다.
- 로그인 정보: Google 계정 식별자, 이메일 주소
- 동기화되는 설정: 차트 설정, 작도, Pine 스크립트, 알람 규칙, 시세창 모양, 관심 종목
이 정보는 앱과 웹 사이에서 설정을 맞추는 데만 사용합니다. 판매하거나 광고에 쓰지 않으며, 사용자 본인의 로그인으로만 읽고 쓸 수 있습니다. 전송은 암호화(HTTPS)됩니다. Google 계정 비밀번호는 CoinFloat이 받지 않습니다.
보관 기간은 사용자가 계정을 삭제할 때까지입니다.
CoinFloat이 Google API에서 받은 정보의 사용과 이전은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

3. 계정 삭제
앱의 설정 탭 > Google 계정 · 동기화 > 계정 삭제, 또는 https://wlgptjd333.github.io/coin-float/delete-account.html 에서 삭제할 수 있습니다. 로그인 정보와 클라우드에 저장된 설정이 바로 삭제되고 별도로 보관하지 않습니다.

4. 기기에 저장되는 정보
위 설정과 차트에 필요한 시장 데이터(체결 요약, 호가 히트맵)는 기기 안에도 저장됩니다. 앱을 삭제하면 함께 삭제됩니다.

5. 네트워크 통신
기능을 제공하기 위해 아래 서비스에 직접 접속합니다. 요청에는 종목 이름과 같은 공개 정보만 포함되며 사용자를 식별하는 정보는 포함되지 않습니다(2번의 Google 제외). 다만 인터넷 연결 특성상 이 서비스들은 IP 주소 등 일반적인 접속 정보를 기록할 수 있습니다.
- Binance 선물 · 현물: 공개 시장 데이터
- Bybit, OKX, Hyperliquid, Bitfinex: "다른 거래소 체결 합산"이나 "비트파이넥스 롱 · 숏" 기능을 켰을 때의 공개 시장 데이터
- Binance 이미지 서버(bin.bnbstatic.com), CoinCap(assets.coincap.io): 코인 로고 이미지
- Google: 2번의 로그인과 동기화를 사용할 때
- GitHub Pages: 웹 버전을 쓸 때의 웹사이트 호스팅

6. 권한
- 다른 앱 위에 표시: 시세창(오버레이)을 화면에 띄우기 위해 사용합니다.
- 알림: 시세 서비스 실행 표시와 차트 알람에 사용합니다.
- 인터넷/네트워크 상태: 시세를 받고 설정을 동기화하기 위해 사용합니다.
- 정확한 알람: 캔들 마감 시각에 맞춰 차트 알람을 확인하기 위해 사용합니다.
- 부팅 완료 수신: 재부팅이나 업데이트 후 켜 두었던 시세창과 알람을 다시 시작하기 위해 사용합니다.
위 권한으로 얻은 정보를 수집하거나 공유하지 않습니다.

7. 제3자 제공
개발자는 정보를 제3자에게 판매하거나 제공하지 않습니다. 2번의 정보는 서비스 제공을 위해 Google(Firebase)에 저장됩니다.

8. 면책
표시되는 시세·지표·추정치는 정보 제공용이며 투자 권유나 자문이 아닙니다. 데이터는 지연되거나 틀릴 수 있습니다.
