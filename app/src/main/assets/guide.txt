1. 왜 지표를 나눠 써야 하나요? (다중공선성 주의)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 같은 계열 지표(이동평균 + 볼린저 + 슈퍼트렌드 + 스퀴즈 모멘텀 등)를 한꺼번에 켜면 모두 '종가'를 변형한 값이라 동시에 초록불이 들어와도 실제 정보는 1개뿐입니다.
• 추정 청산맵 + 호가 벽 + 호가 히트맵 + 볼륨 프로파일 + 피보나치를 동시에 켜면 수평선이 차트를 뒤덮어 정작 중요한 캔들과 가격 구조가 가려집니다.
• 하단 창에 OI + CVD + RSI를 합쳐 놓으면 단위(달러 · 수량 · 0~100)가 달라 스케일이 왜곡됩니다. 반드시 하단 창을 2~3개로 분리하세요.
• 가장 좋은 구성은 [가격 구조 1~2개 + 체결 수급(CVD) + 파생 포지션(OI·청산) + 모멘텀(필요할 때 1개)]처럼 서로 다른 차원의 지표를 하나씩만 조합하는 것입니다.

2. 기본 탑재된 지표 프로필 6종 (차트 › 지표 › 지표 프로필)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⓪ 🎯 역추세 단타 (깔끔) [새 기본값 · 1분~15분봉]
• 메인: EMA(20·50·200) + VWAP(선만) + 거래량(MA20)
• 하단 1창: RSI(14) / 하단 2창: 실시간 청산 (접어 둠 · '펼치기'를 누르면 막대가 보임)
• 용도: 소진 알람이 울렸을 때 보는 화면입니다. 거래량 폭발과 꼬리, 얼마나 과하게 밀렸는지(RSI), 누가 강제로 털렸는지(청산), 되돌아갈 자리(VWAP · EMA)만 남겨 캔들이 가려지지 않습니다.

① 실전 메인 (구조 · 수급) [15분~1시간봉]
• 메인: EMA(20·50·200) + VWAP(당일) + 볼륨 프로파일(화면 구간 POC·VA) + 거래량(MA20)
• 하단 1창: CVD · 델타 (바이낸스 선물 + 현물 CVD 비교 켜짐)
• 하단 2창: 미결제약정(OI) + 실시간 청산($5만 이상 버블)
• 용도: 평소 차트를 볼 때와 알람이 울려 앱을 열었을 때 가장 먼저 확인하는 표준 화면입니다.

② 타점 정밀 (풋프린트 · DOM) [1분~15분봉 진입 · 손절 시]
• 메인: VWAP + Bid/Ask 호가선 + 대량 체결(봉마다 합산) + 실시간 청산 + 풋프린트(Bybit·OKX·Hyperliquid 거래소 합산) + 우측 호가·체결창(DOM)
• 하단 1창: 실시간 청산
• 용도: 주요 지지·저항 가격대에 도달해 실제 진입 타점이나 손절 여부를 정할 때 켭니다. 봉 꼬리 끝에서 풋프린트 불균형(300%↑)이나 대량 흡수가 일어나는지 확인하세요.

③ 고래 · 스윙 (1H · 4H 큰 흐름) [1시간~일봉 방향성 점검]
• 메인: EMA(20·50·200) + 볼륨 프로파일(전체 범위) + 거래량(MA20)
• 하단 1창: 미결제약정(OI) + 펀딩비(예상·연환산)
• 하단 2창: 비트파이넥스 롱 · 숏 (24봉 변화량 모드)
• 하단 3창: RSI (14, 이동평균선 포함)
• 용도: 하루 1~2번 큰 추세 방향과 레버리지 과열 여부를 점검할 때 씁니다. 펀딩비가 과열(+)인데 비트파이넥스 고래 롱이 줄어들면 조정 주의, 하락 후 펀딩비가 음수(-)이고 고래 롱이 늘어나면 매집·숏 스퀴즈 가능성을 봅니다.

④ 알람 복기 · 레짐 (RVOL · CHOP · 다이버전스) [장세 판별]
• 메인: EMA(20·50·200) + 볼린저 밴드(20, 2) + Pine RSI 다이버전스
• 하단 Pine 창: 상대 거래량(RVOL, 20봉·4배 기준) + 초피니스 지수(CHOP, 14)
• 용도: 지금 시장이 추세장인지 횡보장인지 헷갈릴 때, 또는 알람이 울린 자리를 과거 차트에서 복기할 때 켭니다. CHOP이 61.8 위면 횡보장(돌파 매매 자제), 38.2 아래로 내려가며 RVOL이 4배 이상 터지면 추세 시작 신호입니다.

⑤ 클린 차트 (최소 구성)
• 메인: EMA(20·50·200) + 거래량(MA20)
• 용도: 추세선·피보나치·수평선 작도를 하거나 캔들 패턴만 깔끔하게 볼 때 씁니다.

4. 알람이 울렸을 때 확인하는 3단계 순서 (10초 체크리스트)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
거래량·돌파 알람은 '지금 매수/매도하라'는 방향 신호가 아니라 '지금 차트를 열어 확인하라'는 변동성 호출기입니다.

[1단계: 자리 확인 — 메인 차트]
• 지금 가격이 1시간봉 EMA 200과 당일 VWAP 위인가 아래인가?
• 볼륨 프로파일의 최대 매물대(POC)나 가치 영역(VA) 경계를 뚫는 자리인가, 아니면 매물대 한가운데(횡보 구간)인가? 매물대 한가운데서 울린 거래량 알람은 위아래 흔들기일 확률이 높습니다.

[2단계: 주체 확인 — 하단 1창 CVD]
• 가격이 오를 때 선물 CVD와 현물 CVD(점선)가 함께 오르면 '실수요 동반 진짜 상승'입니다.
• 선물 CVD만 급등하고 현물 CVD는 제자리이거나 내려가면 '레버리지 롱 추격'이라 되돌림 위험이 큽니다.

[3단계: 연료 확인 — 하단 2창 OI · 청산]
• 돌파 봉에서 OI가 함께 늘어나면 새 포지션이 진입해 추세에 연료가 붙는 것입니다.
• 급등·급락 봉 끝에 큰 청산 버블($5만~$15만↑)이 연달아 터지고 OI가 급감하면 강제 청산으로 만든 막바지 슈팅(클라이맥스)일 가능성이 높으므로 추격 진입을 멈추세요.

5. 바이낸스 선물 백테스트 실측 요약 (BTC · ETH)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• 15분봉 거래량 급증 (20봉 평균 + 몸통 0.2% 필터):
  - 4배 기준 BTC 하루 1.8회, ETH 하루 2.4회 발생. 신호 후 1시간 변동폭은 평소의 2.07배(BTC) / 1.81배(ETH)로 크게 뛰지만, 신호 캔들 방향으로 그대로 갈 확률은 48~52%이므로 반드시 CVD·매물대 확인 후 진입해야 합니다.
  - 몸통 0.2% 필터를 켜면 위아래 꼬리만 긴 도지 봉(허수 신호)의 약 28%를 걸러내면서 변동성 포착력은 그대로 유지됩니다.
• 고점·저점 돌파 (15분봉 vs 1시간봉):
  - 15분봉 20봉 돌파(필터 없음)는 하루 5.8회 울려 휩소가 많지만, 1시간봉 20봉 돌파 + 거래량 1.5배 확인은 하루 1.1회(변동폭 1.42~1.52배)로 알짜 추세만 포착합니다.
• 1시간봉 RSI 일반 다이버전스:
  - 하루 0.32~0.33회(약 3일에 1번) 발생. EMA 200 추세 방향과 같은 방향(상승장 강세 다이버전스 · 하락장 약세 다이버전스)만 골랐을 때 신호 후 24시간 평균 수익률이 +0.67%로 역추세 진입 대비 뚜렷하게 우수했습니다.
